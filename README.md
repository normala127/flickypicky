## Project Scope (Fork)

This fork of **Flickypicky** was used to explore graph-based recommendation systems using Neo4j.

Key areas of work:
- Graph data modeling of users, movies, and relationships in Neo4j
- Data preparation and ingestion using Python
- Implementation of simple recommendation queries

The project was completed as a learning and academic exercise.

## Skills & Tools Demonstrated

- Neo4j (graph databases, Cypher queries)
- Graph-based recommendation systems
- Python for data preparation and ingestion
- Basic data modeling and exploratory analysis
- Working with real-world datasets
